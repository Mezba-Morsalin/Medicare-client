# 🏥 MediCare Connect

A full-stack healthcare appointment management platform where patients can easily find verified doctors, book appointments, receive prescriptions, make payments, and manage their healthcare journey online.

---

## 🌐 Live Website

🔗 Live Site: https://medicare-connect-swart.vercel.app

---

## 🚀 Features

### 👨‍⚕️ Patient Features

- User Authentication
- Search Doctors
- View Doctor Profiles
- Book Appointments
- Payment Integration
- View Payment History
- View Prescriptions
- Leave Doctor Reviews
- Update Profile

---

### 🩺 Doctor Features

- Doctor Registration
- Doctor Verification Status
- Dashboard Overview
- Manage Schedule
- View Appointments
- Create Prescriptions
- View Patient Reviews
- Update Professional Profile

---

### 👨‍💼 Admin Features

- Dashboard Overview
- Manage Users
- Suspend Users
- Delete Users
- Verify Doctors
- Reject Doctor Verification
- Manage Payments
- Analytics Dashboard

## 💻 Installation

### Clone Repository

```bash
git clone https://github.com/Mezba-Morsalin/Medicare-client

git clone https://github.com/Mezba-Morsalin/Medicare-server
```

### Install Dependencies

```bash
npm install
```

### Run Development Server

Client

```bash
npm run dev
```

Server

```bash
npm run start
```
